# Suggested Commands

- `npm test` - run full test suite.
- `node --test test/<file>.test.js` - run focused test file.
- `node --check <file.js>` - syntax-check an ESM file.
- `npm run dev` - start watch server.
- `npm start` - start server.
- `git status --short --branch` - inspect worktree/branch state.
- `rg --files` and `rg <pattern>` - fast local search. In this environment shell commands may need escalation if bwrap namespace setup fails.
